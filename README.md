# Acoflex Elevate

Create a completely new, premium, modern and highly polished website for **Acoflex PVC / Acoflex Pipe**, a PVC pipe, flexible hose and piping solutions manufacturer in India.

Use the existing website **https://acoflexpvc.com/** as the primary source for ALL company content and information.

Study the existing website carefully and use its:

- Company information
- Product categories and descriptions
- Manufacturing information
- Quality/testing information
- Infrastructure information
- Dealer/distributor information
- Services
- FAQs
- Contact information
- Existing brand identity

Do not copy the existing website's design. Reimagine the entire experience.

## DESIGN

Use your own creative judgment to create a **high-end, modern, premium industrial/manufacturing website**.

I do NOT want a generic corporate template.

Make it feel like a serious, established, technology-driven manufacturing brand.

You decide:

- Color palette
- Typography
- Layout
- Visual hierarchy
- Animation style
- Section structure
- Image treatment
- Navigation style
- Interactions

Prioritize excellent design, spacing, typography, visual storytelling and responsiveness.

Use tasteful modern animations and interactions where they improve the experience. Avoid excessive animation.

The website should look excellent on desktop, tablet and mobile.

## WEBSITE

Create a complete website, not just a landing page.

Include appropriate pages/sections based on the information available on the existing Acoflex website, including:

- Home
- About
- Products
- Product detail pages
- Manufacturing
- Quality / Technology
- Infrastructure
- Dealer / Distributor
- Resources
- Contact
- FAQ

You can improve or reorganize the information architecture if you think it creates a better user experience.

## PRODUCTS

Products must be structured dynamically rather than hard-coded into individual pages.

Create a reusable product system with:

- Categories
- Products
- Product descriptions
- Images
- Features
- Applications
- Specifications
- Technical documents
- Related products

Use the existing Acoflex website for the initial product content.

Do not invent technical specifications, certifications, statistics or claims that are not present in the source material.

## ADMIN PANEL / CMS

A major requirement is a powerful admin panel.

Create an `/admin` area where the Acoflex team can manage the website without editing code.

The admin should eventually allow them to change:

- Homepage headings
- Descriptions
- Banners
- Images
- Videos
- Product content
- Product images
- Product specifications
- Manufacturing content
- Quality content
- Infrastructure content
- FAQs
- Dealer information
- Resources / PDFs
- Contact information
- SEO metadata

They should also be able to add, edit, publish/unpublish and delete products.

Create a clean, professional CMS dashboard rather than a basic CRUD interface.

## MEDIA

Create a media management system so administrators can upload and manage:

- Images
- Videos
- PDFs
- Product documents
- Certificates

Use Supabase Storage.

## LEADS

Add forms for:

- Contact
- Request a Quote
- Dealer/Distributor enquiry

Store submissions in Supabase and make them accessible from the admin panel.

Include basic lead statuses such as:

New
Contacted
Qualified
Converted
Closed

## BACKEND

Use Supabase for:

- Database
- Authentication
- Storage
- Admin users
- Website content
- Products
- Media
- Leads

Structure the database cleanly so the website can be expanded later.

## IMPORTANT

Do not over-engineer the first version.

Focus first on creating an **exceptionally good visual website and a solid underlying architecture**.

Use the existing Acoflex website as the content source, but use your own creativity for the design.

The end result should feel like a completely new digital identity for Acoflex — premium, modern, dynamic and trustworthy.

Build the first version and then we will iterate on the design and functionality together.
